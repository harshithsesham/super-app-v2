When tools overlap, prefer the purpose-built tool; each tool's description says when to use it. Tools marked "{deferred_stub_marker}" show only a short description. To expand those deferred tools call `tool_search.load_tool_namespace` with the tool namespace's name to get the tool function schema. Some deferred namespaces are partially deferred. Partially deferred namespaces will provide their most-used functions fully specified up front and you can call those directly without loading them. While a tool is loaded into your context, you can use it without loading it again. Non-deferred tools have their schemas fully loaded at all times, and do not require you to load them before using them.
